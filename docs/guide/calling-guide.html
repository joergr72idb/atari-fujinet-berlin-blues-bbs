Berlin Blues BBS

How to call the box with telnet: macOS, Windows (PuTTY) and Linux

The Berlin Blues is a single-line mailbox running on an Atari XL with FujiNet. You call it over the internet with a telnet client on port 6502. Only one caller can be online at a time; if the line is busy, try again a bit later. As of 2026-11-14.

The address. In this guide ADDRESS stands for the box's internet address, which you get from the sysop. Replace it with the real address everywhere. The port is always 6502.
Telnet is not secure. Telnet sends everything as plain, unencrypted text, including your user name and password. Anyone along the way (a public Wi-Fi, a network operator) could read it.
  • Use a password for the Berlin Blues that you use nowhere else.
  • Don't write anything in the box that you wouldn't put on a postcard.
Why telnet anyway? The box itself is an 8-bit computer: an Atari XL with a 6502 CPU at 1.79 MHz and 64 KB of RAM. Encrypted connections (SSH, TLS) need far more computing power and memory than that machine has. Many callers also dial in from 8-bit computers (Atari, C64, Schneider/Amstrad CPC) with WiFi modems, and those only speak plain telnet too. Telnet keeps the box open for both: the 8-bit host and the 8-bit callers, just like a mailbox in 1987.

1. macOS

Apple removed the telnet command in macOS 10.13 High Sierra, so current macOS versions don't have it. The easiest way to get it back is the package manager Homebrew.

1.1 Open the Terminal

Finder → Applications → Utilities → Terminal, or press ⌘ Space, type Terminal and press Return. Check first whether telnet is already there:

telnet

If you see command not found: telnet, continue with 1.2. If you see a telnet> prompt, type quit and go to 1.4.

1.2 Install Homebrew (skip if you already have it)

Copy this line from brew.sh into the Terminal and press Return:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
  • It asks for your Mac password (the one you log in with). Nothing is shown while you type; that's normal.
  • It may install Apple's Command Line Tools first. That takes a few minutes.
  • At the end it prints Next steps with two or three commands. On Macs with Apple chips (M1 and newer) you must run them, otherwise the brew command isn't found. Then close the Terminal window and open a new one.

1.3 Install telnet

brew install telnet

1.4 Call the box

telnet ADDRESS 6502

Continue with section 4 (first call).

2. Windows with PuTTY

PuTTY is a free terminal program for Windows that speaks telnet (and SSH).

2.1 Install PuTTY

  • Download it only from the official page: https://www.chiark.greenend.org.uk/~sgtatham/putty/ → Download PuTTY → the 64-bit x86 .msi installer (64-bit Arm for Arm laptops), then run it.
  • Or in a terminal (PowerShell): winget install PuTTY.PuTTY

2.2 Set up the connection

  1. Start PuTTY from the Start menu. The window PuTTY Configuration opens on the Session page.
  2. Host Name (or IP address): ADDRESS
  3. Port: 6502
  4. Connection type: Telnet. In newer PuTTY versions, click Other and pick Telnet from the list next to it. Don't use Raw: the box then can't switch off PuTTY's local echo, and you would see every key twice.
  5. To keep the settings: type Berlin Blues under Saved Sessions and click Save. Next time, double-click that entry.
  6. Click Open. A black window opens; continue with section 4.

The defaults fit: 80 × 24 characters, Backspace works. The window closes by itself after you log off.

Without PuTTY: Windows 10 and 11 still have their own telnet client, it's just switched off. Control Panel → Programs → Turn Windows features on or off → Telnet Client, or in an administrator command prompt: dism /online /Enable-Feature /FeatureName:TelnetClient. Then: telnet ADDRESS 6502

3. Linux

Most distributions don't install telnet by default, but every one has it as a package. Open a terminal and install it:

DistributionCommand
Debian, Ubuntu, Linux Mint, Raspberry Pi OSsudo apt install telnet
Fedora, RHEL, Rocky, AlmaLinuxsudo dnf install telnet
openSUSEsudo zypper install telnet
Arch Linux, Manjarosudo pacman -S inetutils

Then call the box:

telnet ADDRESS 6502

4. First call

The box speaks German. What you'll see, step by step:

1=PC/MAC 2=SCHNEIDER CPC 3=C64 ?which computer are you calling from?1 (PC, Mac or Linux)

  • As a new user you can read right away. You can write once the sysop has approved you.
  • In every menu: * = main menu, 0 = log off. --Mehr-- means "more": Return shows the next page, q stops.
  • After 5 minutes without a key press the box hangs up, so the line is free for the next caller.
  • Please always log off with 0. If the connection hangs, just close the window.
