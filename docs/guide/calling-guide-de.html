Berlin Blues BBS

So rufst du die Box mit Telnet an: macOS, Windows (PuTTY) und Linux

Die Berlin Blues ist eine Mailbox mit einer Leitung, die auf einem Atari XL mit FujiNet läuft. Du rufst sie über das Internet mit einem Telnet-Programm auf Port 6502 an. Es kann immer nur eine Person gleichzeitig online sein; ist die Leitung besetzt, versuch es etwas später noch einmal. Stand: 14.11.2026.

Die Adresse. In dieser Anleitung steht ADRESSE für die Internet-Adresse der Box, die du vom Sysop bekommst. Ersetze sie überall durch die echte Adresse. Der Port ist immer 6502.
Telnet ist nicht sicher. Telnet überträgt alles als lesbaren, unverschlüsselten Text, auch deinen Benutzernamen und dein Passwort. Jeder auf dem Weg dazwischen (ein öffentliches WLAN, ein Netzbetreiber) könnte mitlesen.
  • Nimm für die Berlin Blues ein Passwort, das du sonst nirgends benutzt.
  • Schreib in der Box nichts, was du nicht auch auf eine Postkarte schreiben würdest.
Warum trotzdem Telnet? Die Box selbst ist ein 8-Bit-Computer: ein Atari XL mit 6502-Prozessor (1,79 MHz) und 64 KB Arbeitsspeicher. Verschlüsselte Verbindungen (SSH, TLS) brauchen viel mehr Rechenleistung und Speicher, als diese Maschine hat. Viele Anrufer kommen außerdem selbst mit 8-Bit-Rechnern (Atari, C64, Schneider CPC) über WLAN-Modems, und die können ebenfalls nur einfaches Telnet. Mit Telnet bleibt die Box für beide offen: den 8-Bit-Rechner als Host und die 8-Bit-Rechner als Anrufer, genau wie eine Mailbox 1987.

1. macOS

Apple hat den Befehl telnet mit macOS 10.13 High Sierra entfernt, aktuelle macOS-Versionen haben ihn also nicht mehr. Am einfachsten holst du ihn dir mit dem Paketmanager Homebrew zurück.

1.1 Terminal öffnen

Finder → Programme → Dienstprogramme → Terminal, oder ⌘ Leertaste drücken, Terminal tippen und Return. Prüf zuerst, ob Telnet schon da ist:

telnet

Steht da command not found: telnet, geht es mit 1.2 weiter. Erscheint eine Eingabe telnet>, tipp quit und spring zu 1.4.

1.2 Homebrew installieren (überspringen, wenn schon vorhanden)

Kopier diese Zeile von brew.sh ins Terminal und drück Return:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
  • Es fragt nach deinem Mac-Passwort (dem Anmelde-Passwort). Beim Tippen wird nichts angezeigt, das ist normal.
  • Eventuell installiert es zuerst Apples Command Line Tools. Das dauert ein paar Minuten.
  • Am Ende zeigt es unter Next steps zwei oder drei Befehle an. Auf Macs mit Apple-Chip (M1 und neuer) musst du sie ausführen, sonst wird der Befehl brew nicht gefunden. Danach das Terminal-Fenster schließen und ein neues öffnen.

1.3 Telnet installieren

brew install telnet

1.4 Die Box anrufen

telnet ADRESSE 6502

Weiter mit Abschnitt 4 (der erste Anruf).

2. Windows mit PuTTY

PuTTY ist ein kostenloses Terminalprogramm für Windows, das Telnet (und SSH) kann. Die Bedienoberfläche ist englisch.

2.1 PuTTY installieren

  • Lade es nur von der offiziellen Seite: https://www.chiark.greenend.org.uk/~sgtatham/putty/ → Download PuTTY → den 64-Bit-x86-Installer (.msi; bei Arm-Laptops 64-bit Arm) und führ ihn aus.
  • Oder in einem Terminal (PowerShell): winget install PuTTY.PuTTY

2.2 Verbindung einrichten

  1. PuTTY im Startmenü starten. Das Fenster PuTTY Configuration öffnet sich auf der Seite Session.
  2. Host Name (or IP address): ADRESSE
  3. Port: 6502
  4. Connection type: Telnet. In neueren PuTTY-Versionen auf Other klicken und daneben Telnet aus der Liste wählen. Nicht Raw nehmen: Dann kann die Box PuTTYs lokales Echo nicht abschalten, und du siehst jede Taste doppelt.
  5. Zum Speichern: unter Saved Sessions Berlin Blues eintippen und auf Save klicken. Beim nächsten Mal genügt ein Doppelklick auf den Eintrag.
  6. Auf Open klicken. Ein schwarzes Fenster öffnet sich; weiter mit Abschnitt 4.

Die Voreinstellungen passen: 80 × 24 Zeichen, die Rücktaste funktioniert. Nach dem Abmelden schließt sich das Fenster von selbst.

Ohne PuTTY: Windows 10 und 11 haben noch einen eigenen Telnet-Client, er ist nur ausgeschaltet. Systemsteuerung → Programme → Windows-Features aktivieren oder deaktivieren → Telnet-Client, oder in einer Eingabeaufforderung als Administrator: dism /online /Enable-Feature /FeatureName:TelnetClient. Dann: telnet ADRESSE 6502

3. Linux

Die meisten Distributionen installieren Telnet nicht von selbst, aber alle haben es als Paket. Öffne ein Terminal und installier es:

DistributionBefehl
Debian, Ubuntu, Linux Mint, Raspberry Pi OSsudo apt install telnet
Fedora, RHEL, Rocky, AlmaLinuxsudo dnf install telnet
openSUSEsudo zypper install telnet
Arch Linux, Manjarosudo pacman -S inetutils

Dann die Box anrufen:

telnet ADRESSE 6502

4. Der erste Anruf

Was du der Reihe nach siehst:

Die Box zeigtBedeutungDu tippst
BERLIN BLUES BOX - BITTE <RETURN> DRUECKENReturn drückenReturn
1=PC/MAC 2=SCHNEIDER CPC 3=C64 ?von welchem Computer rufst du an?1 (PC, Mac oder Linux)
Gaeste bitte <RETURN> druecken! Username ==>dein Benutzername; nur Return = Gasteinen Namen (3-15 Buchstaben/Ziffern)
Dich kenne ich noch nicht. Neu eintragen (J/N)?neuer Name: eintragen?j
Neues Passwort (4-16 Zeichen) ==> / Nochmal ==>Passwort wählen und wiederholenein Passwort, das du sonst nirgends nutzt
  • Als neuer Benutzer kannst du sofort lesen. Schreiben kannst du, sobald der Sysop dich freigeschaltet hat.
  • In jedem Menü: * = Hauptmenü, 0 = abmelden. Bei --Mehr-- zeigt Return die nächste Seite, q bricht ab.
  • Nach 5 Minuten ohne Tastendruck legt die Box auf, damit die Leitung für den Nächsten frei wird.
  • Bitte immer mit 0 abmelden. Hängt die Verbindung, schließ einfach das Fenster.
